# IMD Hardware - E-commerce Platform

![IMD Hardware Logo](https://imdhardware.com/images/logo.jpeg)

A premium, high-performance e-commerce platform for **IMD Hardware**, a leading manufacturer and supplier of door locks, handles, and architectural hardware. Built with modern web technologies to provide a seamless shopping experience with innovative features like 3D product visualization.

## 🚀 Features

- **Advanced Product Catalog**: Browse a wide range of door locks, handles, aldrops, and security fittings.
- **3D Model Viewer**: Interactive 3D product visualization using `@google/model-viewer` for an immersive shopping experience.
- **Enhanced SEO (AEO/GEO)**: Optimized for traditional search engines and AI-driven answer engines with rich structured data and dynamic metadata.
- **Secure Payments**: Integrated with Razorpay for safe and reliable transactions.
- **Responsive Design**: Fully mobile-responsive interface built with Tailwind CSS.
- **QR Code Integration**: Seamless product tracking and interaction via QR codes.
- **Order Management**: Comprehensive order tracking and dark-themed PDF/DOCX export capabilities.
- **Professional Analytics**: Admin dashboard for sales and order insights.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations/Gallery**: [Swiper](https://swiperjs.com/) & [Splide](https://splidejs.com/)
- **3D Rendering**: [Three.js](https://threejs.org/) & [Model Viewer](https://modelviewer.dev/)
- **SEO**: [React Helmet Async](https://github.com/staylor/react-helmet-async)
- **Utilities**: [Axios](https://axios-http.com/), [js-cookie](https://github.com/js-cookie/js-cookie), [html2pdf.js](https://ekoopmans.github.io/html2pdf.js/)

## 📦 Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/RajanRathod777/imd-hardware-react.git
   cd imd-hardware-react
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Set up Environment Variables**:
   Create a `.env` file in the root directory and add:

   ```env
   VITE_SERVER_API_URL=your_api_url
   ```

4. **Run the development server**:

   ```bash
   npm run dev
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```
